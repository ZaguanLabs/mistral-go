# Mistral Go SDK v2.9.4 Release Notes

This release aligns the Go SDK with the official Mistral Python SDK v2.9.4.

- Realtime session requests accept `ttl_seconds`.
- Message token usage includes `settings_tokens`.
- Prompt records include creator and version-creation metadata.
- Vespa indexes expose embedding dimensions.
- Tempo trace attributes support floating-point values.
- Usage metadata preserves the selected service tier.
